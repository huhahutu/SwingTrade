**要件定義書：フェーズ2 - RAG自動化とベクターDBの組み込み**

**1. 目的・概要**
取引完了時のログとニュース本文をベクターDBへ自動登録します。毎朝の判定時には最新ニュースと類似する過去事例（特に損失が出た失敗パターン）を自動検索（Retrieval）し、Gemini 2.5 Flash のプロンプトへコンテキストとして自動挿入（Augmentation）するパイプラインを構築します。

**2. 技術スタック**

* **ベクターDB**: Chroma DB（または PGvector / Qdrant）


* **主要言語/環境**: Python (FastAPI)


* **静的解析**: Ruff, mypy (Strict モード)



**3. 実装機能要件**

* **ベクターDBの組み込みと自動更新**
* Chroma DB 等のベクターストアを組み込み、データ永続化の構成を作成する。


* 取引完了（決済）時、取引ログ（`trade_outcome`: WIN/LOSS 等）とニュース本文を埋め込みベクトル（Vector Embeddings）に変換して自動保存する。




* **類似過去事例の自動検索 (Retrieval)**
* 朝7:00の判定時、新たに取得したニュースのベクトル表現を作成する。


* 過去ログから「ニュース内容が類似している取引結果」の上位k件（例: 3件）を自動検索する。




* **動的プロンプトの生成 (Augmentation)**
* 検索された過去事例（「以前〇〇の条件でBUY判定したが損失が出た」等）を、Gemini 2.5 Flash に渡すプロンプトへ自動的にコンテキストとして挿入する処理を実装する。
